# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 stock, blend, feed, check。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `batch`、`parent`、`grams` 排列。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

投料边指向原料批次。按拓扑顺序用精确比例传播克数，多路径汇总至同一原料批号。验证所有输入、输出和库存余额。

同一原料批号跨业务组出现时视为同一物理原料批：可用量取各组申报库存的最大值，领用量按组内投料边累计。跨组累计领用超过可用量时，所有领用组进入停发名单，批次不可签发。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。`shared.csv` 含两个各自平衡但共同领用同一原料批而合计超占的组。
